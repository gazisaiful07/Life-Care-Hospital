# 🏥 Life Care Medical Website

A modern, responsive medical website for **Life Care**, designed to showcase professional healthcare services, doctors, and nursing staff.

---

## 🌐 Project Overview

**Life Care** is a professional medical center featuring:

* 👨‍⚕️ 30+ Professional Doctors
* 👩‍⚕️ 100+ Skilled Nurses
* 🕒 24/7 Emergency Services
* ❤️ Patient-focused care

This website is built to provide a clean, trustworthy, and user-friendly experience for patients.

---

## 🚀 Features

* ✅ Fully Responsive (Mobile, Tablet, Desktop)
* 🎨 Modern Medical UI Design
* 📱 Mobile-Friendly Navigation (Hamburger Menu)
* 🧾 Appointment Booking Form with Validation
* 👨‍⚕️ Doctors Section with Profile Cards
* 👩‍⚕️ Nurses Information Section
* 🏥 Services Section
* 📞 Contact Form & Information
* ✨ Smooth Animations & Hover Effects

---

## 🛠️ Technologies Used

* JavaScript (Vanilla JS)

   OR open with Live Server in VS Code
